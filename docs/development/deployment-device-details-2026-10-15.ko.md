# 배포별 익명 설치·이벤트 상세 검증

2026-10-15 운영 환경 `https://flora.uulab.co.kr` 검증 기록입니다.

## 사용 방법

프로젝트 → OTA 배포 → 배포 행의 **기기별 적용 현황**을 누릅니다.
`/apps/:appId/ota/:deploymentUuid`에서 해당 앱·배포의 익명 설치별 다운로드·적용·재시작,
실패 단계·원인, 롤백·누적 복구 여부를 확인합니다. **상세 이벤트 보기**는 선택한 설치만 조회합니다.
기술 식별자는 접힌 기술 정보에 두고, 운영 결과를 먼저 표시합니다.

설치 별칭은 앱·배포 범위에서만 유효합니다. 실제 기기 이름이나 앱 사이의 동일 사용자를
추적하는 식별자가 아니며, 서버 응답에 SDK 설치 UUID·보고 티켓·IP를 내보내지 않습니다.
SDK 자체 보고와 별도로 수행한 운영자 네이티브 검증은 서로 다른 근거입니다.

| Reward | 다운로드·적용·재시작 확인 | 다운로드·적용·재시작 확인 | 다운로드 / 네트워크 연결 실패 및 네이티브 작업 실패, 복구 확인 |

최신 6개 배포는 각각 보고 설치 1개·누적 적용률 100%입니다. 이는 보고한 QA 설치의 결과이며
전체 사용자 기기의 적용률이나 물리 기기 검증을 뜻하지 않습니다. 총 9개 배포 상세를 실제
인증 브라우저에서 API 결과와 대조했습니다. 화면 오류 0건, 데스크톱 1440×1080 및 모바일
390×844에서 가로 넘침이 없었습니다. 앱 선택을 바꾸면 해당 앱 OTA 목록으로 이동하고
이전 앱의 설치 카드가 제거되며, 이전 배포 UUID를 새 앱에 재사용하지 않습니다.

기존 QA Android 에뮬레이터에서 세 앱의 프로세스를 재시작하고 기존 OTA 번들 실행과
서명·다운로드 파일 무결성, APK 및 앱 데이터 보존을 재확인했습니다.
검증 파일은 Isso 40개·Promise 51개·Reward 57개입니다.
세 앱 모두 실제 신규 `launch_confirmed` 이벤트 1건이 운영 타임라인에 보관·표시됐습니다.
Isso는 첫 재시작 후 보고 큐에 1건이 남아 추가 재시작으로 전송을 확인했습니다.
최종 세 앱 보고 큐는 모두 0건입니다. 이번 작업은 새 OTA 게시나 다운로드 전체 과정을
다시 수행한 것이 아니며, iOS 설치 결과는 기존 보존 기록을 검증했습니다.

## 과거 기록과 보관 범위

이전 버전은 누적 플래그·실패 코드·일부 확인 시각만 저장했습니다. 당시 저장하지 않은
다운로드 시각이나 이벤트 순서를 재구성하지 않습니다. 해당 설치는 **과거 일부 세부 이벤트
미기록**으로 구분하고, 이후 수신한 이벤트만 타임라인에 추가합니다. 빈 타임라인이어도 기존
성공·실패·복구 결과를 유지합니다. 실제 보고 시각과 서버 수신 시각을 각각 표시합니다.

새 이벤트 저널은 기존 Durable Object SQLite에 테이블과 인덱스를 추가합니다.
설치별 256개·전체 50,000개 상세 이벤트를 보관하며, 한도에 도달하면 기존 이벤트를
삭제하지 않고 생략 건수를 표시합니다. 한도 이후에도 기존 집계 및 유효 보고 수신은
계속됩니다. 중복 보고는 같은 이벤트를 다시 쌓지 않습니다. 7일 재전송 방지 캐시의
만료는 이 상세 저널을 삭제하지 않습니다.

복구 표시는 보고된 실패 이후의 적용 실행 확인과 재시작 확인을 모두 받은 누적 결과입니다.
미보고 상태를 실패·0%로 바꾸지 않으며, 복구 보고 자체를 임의로 생성하지 않습니다.

## 조회량·접근·실패 처리

- 설치 목록 및 이벤트는 각각 20개씩 수동 페이지 조회합니다. 각 요청은 배포 범위 확인을
  위한 인덱스 D1 조회 2회와 한정된 DO 조회를 수행하며 D1 쓰기는 없습니다.
- 직접 상세 URL을 열 때 `/operations` 전체 이력을 추가로 읽지 않습니다.
- 60초 캐시, 목록 8페이지·이벤트 16페이지 상한, 같은 요청 합치기 및 동시 요청 4개 상한을 둡니다.
- 실제 화면에서 목록·이벤트를 캐시 기간 내 다시 열 때 상세 API 요청 0건,
  상세 화면에서 약 69초 대기할 때 추가 브라우저 API 요청 0건을 확인했습니다.
- 브라우저의 해당 읽기 요청만 실패시킨 시험에서 마지막 결과를 유지하고,
  **다시 시도** 후 정상 화면으로 복구했습니다. 이 시험은 SDK 네트워크 실패 이력과 별개입니다.
- 앱·배포·소유자 범위에 묶인 암호화 참조/커서, 인증 취소, 변조 및 다른 앱에서의 재사용을
  서버 통합 테스트로 검증했습니다. 새 JS 모듈은 비로그인 요청에 실제 401을 반환합니다.
