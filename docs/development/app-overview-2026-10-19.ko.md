# 앱 상세 개요 고도화 — 2026-10-19

승인된 밝은 앱 카드형 프로젝트 목록을 앱 상세 개요까지 이어갑니다. 앱 아이콘·이름·GitHub 저장소·브랜치를 먼저 보여주고, OTA 배포와 Runner 페이지로 바로 이동합니다.

## 운영 정보

- iOS·Android별 최근 OTA 게시 시각과 SDK 보고 설치 기준 적용률을 두 패널로 표시합니다. 다운로드·적용·재시작 수는 서로 겹칠 수 있는 설치 수이며 합산하지 않습니다.
- 보고가 없으면 적용률은 `미확인`, 각 단계는 `—`입니다. 게시 성공에서 기기 적용 성공을 추정하지 않습니다.
- 미복구와 해결된 OTA 문제는 별도로 표시하고 해당 앱·배포의 기기 이력으로 연결합니다. 롤백 원래 문제 연결은 기존 검증된 계보 정보를 그대로 사용합니다.
- 실패 원인·누적 보고·실행 환경·이전 실패 후 회복 수치는 각 플랫폼의 닫힌 펼침 영역에 유지합니다. GitHub·Runtime·자동 배포 정책 및 기술 식별자도 펼쳐 확인합니다.
- Runner 현재 상태는 준비된 조회 결과와 기존 2분 신선도 기준을 모두 만족할 때만 표시합니다. 갱신 중에는 마지막 확인 이력임을 표시하고 연결 상태를 미확인으로 처리합니다.

## 데이터 및 조회 경계

렌더러는 기존 프로젝트 요약·선택 앱의 소스/자동 배포 응답만 사용합니다. 새 API, DB 스키마 변경, 자동 폴링, 배포·키 변경을 추가하지 않습니다. 펼침은 브라우저 기본 동작이며 네트워크 요청이 없습니다. 링크는 같은 앱 경로를 검증해 SPA로 이동하고 수정키 클릭은 브라우저 기본 동작을 유지합니다.

요약의 앱 ID뿐 아니라 개별 배포·텔레메트리의 앱·플랫폼·배포 ID도 확인합니다. 다른 앱이나 플랫폼의 게시 정보는 `게시 상태 미확인`으로 처리합니다.

아이콘은 기존 `project-branding.js`의 설치별 매핑을 재사용합니다. 허용된 로컬 이미지가 없으면 앱 이름의 첫 글자를 표시합니다. 이 변경에 특정 운영 앱 아이콘이나 개인정보를 포함하지 않습니다.
