원장에 저장된 상태 변경

    실행은 기본적으로 꺼져 있습니다. PC에서 사전 등록한 설정을 명시적으로 허용한 경우에만 웹에서 실행·중지를 요청할 수 있습니다. 이 Runner는 신뢰하는 코드 전용이며 OS 격리 샌드박스가 아닙니다. 외부 Provider·스토어 배포·OTA는 실행하지 않습니다.

    빌드 작업 등록

    등록 정보는 작업 생성 후 바뀌지 않습니다. 실제 Runner와 저장소 정보를 사용하세요.

    로컬 빌드 실행 확인

    사전 검토한 설정으로 이 PC에서 코드를 실행합니다. 소스 커밋과 Runner를 확인하세요.

    웹에서 명령이나 경로를 변경할 수 없습니다. 네이티브 서명·실기기 설치 성공을 보장하지 않습니다.

    새 작업으로 다시 준비

    원본 실패·취소 이력을 보존하고 같은 소스와 Runner로 새 미승인 작업을 만듭니다. 자동 실행하지 않습니다.
