선택한 프로젝트

GitHub 연결 · Flora OTA

선택한 앱의 설치 권한으로 소스를 읽고 고정 commit을 확인합니다. 공개 CONFIG에는 GitHub 인증 정보를 넣지 마세요.

동적 app.config.ts / JS는 Flora에서 실행하지 않습니다. 같은 commit의 앱 루트에서 아래 명령으로 설정을 내보내고 JSON 파일을 선택한 뒤 소스를 동기화하세요.

npx expo config --type public --json
PC Runner · 자동 export / OTA

GitHub 커밋을 Flora가 감지하면 연결된 PC Runner가 iOS·Android export와 OTA 게시를 수행합니다. GitHub Actions는 필요하지 않습니다. PC가 켜져 있고 Runner와 Docker가 실행 중이어야 합니다. Flora SDK와 체크인한 flora.config.json 선언을 commit에 고정합니다. 선언 확인은 설치된 바이너리나 기기 OTA 동작 검증을 뜻하지 않습니다.

앱별 연결 준비

    Runner 실행 설정과 시작 안내

    등록 토큰은 한 번만 표시됩니다. 지금 소스 밖의 runner.json에 저장하고 chmod 600을 적용하세요. 검증한 이미지 digest와 토큰을 직접 채운 뒤 flora-ota-runner --config /private/runner/runner.json으로 Docker 사전 검사를 거쳐 실행하세요. 재부팅 후 시작하려면 PC의 자동 시작 서비스로 등록하세요. 이 화면의 온라인 상태와 마지막 연결 시각으로 실제 연결을 확인할 수 있습니다.
    자동 OTA 꺼짐 · 명시적으로 저장한 뒤 적용됩니다.
    저장한 channel과 선택한 모든 플랫폼에 적용됩니다. 각 플랫폼의 배포 결과는 이력에서 확인할 수 있습니다. 서버의 GitHub webhook을 /api/github/webhook으로 설정하세요. Webhook 인증 비밀은 서버에만 둡니다.
    이 앱의 Runner 등록
    Runner는 별도 실행 호스트에서 동작합니다. 등록만으로 export가 실행되거나 게시가 완료되지 않습니다.
    한 번만 표시하는 Runner 기계 토큰입니다. 사용자 비밀번호나 공개 CONFIG에 넣지 마세요. 이 화면을 벗어나면 지워집니다.
    이 앱의 자동 배포 로그
    수동 · export 파일 OTA 게시
    수동 export 파일 배포
    실제 Metro 또는 선택한 OSS export 도구의 파일과 동일한 commit, 플랫폼 및 runtime으로 배포합니다. 파일 선택은 운영자 제공 자료이며 검증된 빌드 증거가 아닙니다. OTA는 앱의 네이티브 코드나 스토어 바이너리를 바꾸지 않습니다.
    OTA 전체 게시 이력
    공개 CONFIG 설정
    대문자 키와 문자열 값으로 된 JSON 객체 · 최대 64개 키, 값당 2,048자, 전체 8 KiB. 비밀번호, 토큰 등 인증 정보를 입력하지 마세요. 실행 환경에 자동 적용되지 않습니다.
