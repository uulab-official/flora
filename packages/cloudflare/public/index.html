저장소 접근 설정

Flora는 설치된 GitHub App의 저장소 권한을 사용합니다. 개인 OAuth로 모든 저장소를 읽는 연결이 아니며, GitHub 계정 연결과 저장소 접근 권한은 별개입니다. 목록에 없는 앱은 저장소 접근 설정에서 Flora App에 허용한 뒤 위의 GitHub 연결 확인을 눌러 새로 불러오세요. All repositories를 선택하면 전체 저장소를 허용합니다. Flora가 권한을 자동으로 확대하지는 않습니다. 모노레포는 아래 앱 폴더를 지정하세요. 선택한 저장소는 프로젝트 등록과 함께 연결됩니다.

저장소 최상위에 앱이 있으면 . 을 사용하세요.

Flora OTA 서명

앱별 OTA 서명 키는 서버가 관리합니다. SDK에는 공개 인증서만 포함합니다. 네이티브 앱의 최초 빌드 서명은 별도 빌드 과정에서 준비합니다.

SDK 공개 인증서 다운로드
수동 · export 파일 OTA 게시

수동 export 파일 배포

실제 Metro 또는 선택한 OSS export 도구의 파일과 동일한 commit, 플랫폼 및 runtime으로 배포합니다. 파일 선택은 운영자 제공 자료이며 검증된 빌드 증거가 아닙니다. OTA는 앱의 네이티브 코드나 스토어 바이너리를 바꾸지 않습니다.

OTA 전체 게시 이력

PC Runner · 자동 export / OTA

GitHub 커밋을 Flora가 감지하면 연결된 PC Runner가 iOS·Android export와 OTA 게시를 수행합니다. GitHub Actions는 필요하지 않습니다. PC가 켜져 있고 Runner와 Docker가 실행 중이어야 합니다. Flora SDK와 체크인한 flora.config.json 선언을 commit에 고정합니다. 선언 확인은 설치된 바이너리나 기기 OTA 동작 검증을 뜻하지 않습니다.

고급 · 선택형 GitHub Actions 연결

GitHub Actions로 자동 배포

EAS 없이 GitHub 실행 환경에서 export합니다. 앱 저장소의 무료 Actions 할당량을 사용하며 초과 실행은 계정의 지출 제한을 따릅니다. 초기 SDK 네이티브 빌드는 별도로 필요합니다.

Workflow 다운로드
실행 권한을 저장하고 아래 channel·플랫폼의 GitHub push 정책을 먼저 켜서 저장하세요. 그다음 YAML을 저장된 배포 branch의 .github/workflows/flora-ota.yml에 commit·push하세요. 이 화면은 저장소 파일을 변경하지 않습니다. 등록 권한은 실행 중이나 기기 적용을 의미하지 않습니다. 기본 UULab Workflow는 flora.uulab.co.kr 전용입니다. 자체 호스팅은 해당 서버에 맞는 Runner를 먼저 준비하세요.
앱별 연결 준비
    

    PC Runner 연결 설정
    등록 토큰은 한 번만 표시됩니다. 지금 소스 밖의 runner.json에 저장하고 chmod 600을 적용하세요. 앱마다 별도 work·recovery 경로를 사용하고 recovery와 토큰 파일은 컨테이너에 마운트하지 마세요. registry 의존성 준비 뒤 export는 네트워크 없이 실행합니다. resourceProfile 이름 github-hosted는 PC에서도 사용하는 자원 프로필이며 Actions 연결이 아닙니다. pnpm 앱은 검증한 pnpm 포함 이미지가 필요합니다. 검증한 이미지 digest와 토큰을 직접 채운 뒤 flora-ota-runner --config /private/runner/runner.json으로 Docker 사전 검사를 거쳐 실행하세요. Docker VM의 rootful 엔진이 필요합니다. macOS PC 서비스는 로그인 후 자동 시작하며, PC가 잠들거나 꺼지면 배포가 대기합니다. 이 화면의 온라인 상태와 마지막 연결 시각으로 실제 연결을 확인할 수 있습니다.
    

    

    자동 OTA 꺼짐 · 명시적으로 저장한 뒤 적용됩니다.
    저장한 channel과 선택한 모든 플랫폼에 적용됩니다. 각 플랫폼의 배포 결과는 이력에서 확인할 수 있습니다. 서버의 GitHub webhook을 /api/github/webhook으로 설정하세요. Webhook 인증 비밀은 서버에만 둡니다.
    

    이 앱의 Runner 등록
    Runner는 별도 실행 호스트에서 동작합니다. 등록만으로 export가 실행되거나 게시가 완료되지 않습니다.
    

    한 번만 표시하는 Runner 기계 토큰입니다. 사용자 비밀번호나 공개 CONFIG에 넣지 마세요. 이 화면을 벗어나면 지워집니다.

    이 앱의 네이티브 Runner 등록
    기존 OTA Runner 토큰과 다른 권한입니다. 앱과 플랫폼마다 따로 등록하세요. 등록만으로 PC에서 실행되지는 않습니다.
    

    한 번만 표시하는 기계 토큰입니다. 안전한 Runner 설정 파일에 보관하세요. 앱 전환·새로 확인·로그아웃 시 지워집니다.
    

    

    네이티브 빌드 · 서명
    등록한 서명 키의 버전과 GitHub 커밋을 고정해 PC Runner에 요청합니다. EAS·Actions 없이 동작하며, iOS는 Mac과 Xcode가 필요합니다. 빌드 성공은 스토어 제출이나 기기 설치를 뜻하지 않습니다.
    

    iOS는 배포 인증서와 프로파일, Android는 Keystore만 전달합니다. Google Play·APNs·FCM 키는 이 서명 요청에 포함하지 않습니다.

    인증서 · Google 키 · 푸시 키
